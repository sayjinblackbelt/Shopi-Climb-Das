# Prompt 01 — MVP inicial

Este foi o prompt-base utilizado para orientar a criação da primeira versão jogável do Shopi no Base44.

## Objetivo

Criar um jogo 2D de plataforma arcade vertical com Shopi como entregador, Etvaldo como ajudante e um cliente problemático como obstáculo principal da primeira fase.

## Diretrizes centrais

- jogo original, sem copiar personagens ou assets de obras existentes;
- primeira fase em um prédio;
- Shopi carrega uma caixa;
- Etvaldo precisa ser encontrado/resgatado;
- Tabacudo é o primeiro cliente/boss;
- cliente lança objetos para dificultar a subida;
- plataformas e escadas formam a progressão vertical;
- controles para desktop;
- estrutura preparada para futuras fases;
- prioridade em um MVP funcional e jogável.

## Observação

A versão completa do prompt pode ser mantida também no histórico desta conversa. Este arquivo registra os princípios essenciais utilizados para a geração inicial.
