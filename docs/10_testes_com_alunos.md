# Diário de Testes com Alunos

Documento destinado ao registro dos testes reais do Shopi — Entregas Impossíveis com as turmas.

A regra do projeto é simples: uma funcionalidade só deve ser marcada como concluída quando estiver implementada no jogo e validada em uso real.

## Registro de teste

Para cada sessão, registrar:

- **Data:**
- **Turma:**
- **Quantidade de alunos:**
- **Dispositivo:** computador / celular / tablet
- **Navegador:**
- **Fase testada:**
- **Dificuldade:** Entrega Tranquila / Entrega Complicada / Entrega Impossível
- **Resultado:** concluído / parcial / não concluído
- **Problemas encontrados:**
- **Comentários dos alunos:**
- **Pontos positivos:**
- **Pontos de frustração:**
- **Correção necessária:**
- **Decisão:** manter / ajustar / remover

## Roteiro da primeira rodada

### 1. Acesso

- Abrir a página oficial do projeto.
- Confirmar se o jogo carrega.
- Confirmar se o botão de abertura em nova aba funciona.

### 2. Controles

- Testar movimento.
- Testar pulo.
- Testar escadas.
- Em celular, testar os controles de toque.

### 3. Progressão

- Jogar a Fase 1.
- Avançar pelas seis fases.
- Observar checkpoints e vidas.
- Testar pelo menos uma vez cada dificuldade.

### 4. Pontuação

Quando o placar por fase e o placar geral estiverem implementados:

- concluir uma fase e registrar a pontuação;
- repetir a mesma fase com pontuação maior;
- confirmar substituição do melhor resultado;
- repetir com pontuação menor e confirmar preservação do recorde;
- confirmar soma dos seis melhores resultados no placar geral;
- confirmar exibição da dificuldade usada;
- sair e retornar ao jogo para validar persistência.

## Critérios de aprovação

Uma rodada é considerada aprovada quando:

- o jogo pode ser acessado sem orientação técnica;
- os controles são compreendidos pelos alunos;
- a progressão funciona;
- não existe bloqueio crítico que impeça concluir uma fase;
- o placar apresenta resultados coerentes, quando implementado;
- problemas recorrentes são registrados para correção posterior.
