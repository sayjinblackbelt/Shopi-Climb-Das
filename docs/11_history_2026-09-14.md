# Improvement History — 2026-09-14

## Purpose

Record the improvements implemented during the 2026-09-14 cycle and the issues found during testing.

## Critical flow correction

The main campaign progression flow was corrected, including:

- level-to-level progression;
- level unlocking and level selection;
- campaign continuation;
- pause with continue, restart, settings and exit;
- Game Over recovery and level selection;
- level completion and next-level access;
- protection against premature Chapter 1 completion;
- correct campaign completion at Level 16.

The correction was tested and considered functional by the author.

## Gameplay improvements — second prompt of the day

A new improvement cycle focused on:

- movement feel;
- jump response;
- platform readability;
- level pacing;
- difficulty progression;
- head-butt interaction;
- visual and audio feedback;
- camera;
- checkpoints;
- scoring;
- customer identity;
- Shopi/Etvaldo relationship;
- delivery identity.

Existing mobile controls were preserved because they were already working well.

## Delivery Code

Starting with Level 6, each delivery has a simple delivery code, using a format such as:

`SHP-06-EDV-4721`

The purpose is to create a more realistic logistics/delivery feel without turning the code into a complex system.

The code may appear at the beginning/end of a delivery and occasionally on labels or environmental elements.

## Issue found during testing

### Level 11 — The Hospital

A point was found where the jump between two sections of the level is **not possible**.

Planned correction for the next cycle:

1. reduce the gap between the two sections; **or**
2. add an intermediate support/platform.

The fix should preserve challenge while removing the impossible block.

## GitHub Pages

The project portal received a **global visitor counter**, independent from the game's leaderboard.

The integration uses an external counter service compatible with static pages, without requiring a project backend.
