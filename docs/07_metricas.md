# Métricas do projeto

## Objetivo

Registrar indicadores úteis para acompanhar o uso do jogo e orientar futuras melhorias.

## Contador de visitantes

**Status:** planejado.

O contador deverá registrar visitas de forma global e persistente, evitando contar múltiplas vezes a mesma sessão apenas por navegação interna ou atualização de componentes.

Exibição sugerida na interface:

`VISITANTES: 000123`

## Métricas futuras

Além de visitantes, o projeto poderá acompanhar:

- partidas iniciadas;
- partidas concluídas;
- derrotas;
- tempo médio de partida;
- pontuação média;
- melhor pontuação;
- fase mais jogada;
- percentual de jogadores em desktop e celular.

## Privacidade

Registrar somente os dados necessários para análise do produto. Não armazenar informações pessoais identificáveis sem necessidade e não publicar dados sensíveis no repositório.

## Uso das métricas

As métricas devem servir para responder perguntas concretas:

- O jogo está sendo acessado?
- Os jogadores estão conseguindo concluir a primeira fase?
- O jogo é mais utilizado no celular ou desktop?
- A dificuldade está adequada?
- O ranking está estimulando novas partidas?

As decisões de desenvolvimento devem priorizar evidências de uso e feedback dos jogadores.
