# Ranking e competição

## Objetivo

O ranking registra os melhores desempenhos dos jogadores e cria incentivo para repetir a fase, melhorar tempo e pontuação.

## Dados mínimos recomendados

- nome/apelido do jogador;
- pontuação;
- tempo de conclusão;
- fase;
- data do registro.

## Regras de apresentação

O ranking deve ser simples de compreender e priorizar os melhores resultados.

Evitar expor dados pessoais desnecessários.

## Integridade

O sistema deve validar dados básicos de pontuação e tempo no backend disponível, quando possível. Não confiar apenas em valores enviados pelo cliente.

## Futuro

O ranking poderá evoluir para:

- ranking por fase;
- ranking geral;
- recorde pessoal;
- melhores tempos;
- filtros por período;
- temporadas ou desafios especiais.
